# Task 3 — Sales Dashboard Using Power BI

## Objective
Create an interactive sales dashboard to identify business trends and performance.

## Visualizations
- KPI cards for key sales metrics
- Top 10 products by sales
- Country-wise sales analysis
- Monthly sales trend
- Country and month slicers for interactive filtering

## Tools Used
Microsoft Power BI Desktop

## Deliverable
Interactive Power BI sales dashboard (.pbix file)
